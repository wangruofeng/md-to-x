# MD to X 实现计划

1. 确认真实 X 编辑器 DOM 与粘贴能力；建立 Markdown 解析和安全过滤。验证：转换单元测试。
2. 实现侧栏的导入、编辑、预览、本地草稿与图片目录。验证：本地浏览器操作及窄屏截图。
3. 实现编辑器检查、受保护的写入及图片进度。验证：适配器测试与实际 X 新草稿测试（账号允许时）。
4. 打包扩展，补齐安装和使用说明。验证：完整测试、构建、成品文件检查。

风险：X 页面 DOM 与粘贴行为可能变动。适配器集中隔离，发生不确定情况停止写入并提示；对已有内容拒绝覆盖。

技术选择：无框架原生侧栏避免不必要体积；无后端。权限限定 X，网络图片站点按需授权。开发预览与真实扩展模式明确区分。
