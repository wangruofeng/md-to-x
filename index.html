    从 Markdown 到 X 长文

    1. 导入 Markdown 文件，也可以直接粘贴正文。
    2. 切换预览，检查标题和格式；有本地图片时，选择文章所在文件夹。
    3. 打开 X 的「文章」，新建空白草稿，点击「检查连接」。
    4. 点击「写入 X」，等待图片和正文导入，再到 X 检查和发布。

    插件只写入空白草稿，避免覆盖已有内容。X 账号需要具备长文创作权限。

    表格按 X 原生 Markdown 内容块导入，保留行列和对齐；代码块保留语言标记、缩进和空行。图片在写入前需全部准备就绪。
