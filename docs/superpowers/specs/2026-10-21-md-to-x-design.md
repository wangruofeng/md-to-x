# MD to X 设计

用户已于 2026-10-21 确认本范围，直接实现，无需再次确认。

## 目标

Chrome Manifest V3 原生侧边栏扩展，将本地 Markdown 导入 X Articles 草稿。独立项目位于 speed 同级的 md-to-x。界面参考 XXD xPoster 的编辑工具栏、预览及底部写入操作，自行实现代码与视觉细节。

## 首版范围

- 选择、拖入单个 Markdown 或粘贴文本；识别 frontmatter 标题与首个一级标题。
- 编辑 / 预览切换，基础格式工具，字数、图片统计。
- 支持标题层级、粗斜体、列表、链接、引用；代码和表格按 X 能力处理并明确提示。
- 手动选择图片目录以解析相对路径；网络图片只在用户请求加载时访问。
- 本地自动保存、草稿列表；内容不会发给第三方服务。
- 检测当前 X 长文草稿；写入标题、正文与图片；显示进度和失败原因。
- 保护已有内容，默认只允许写入空白草稿；不调用 X 私有 API、不点击发布。

## 实现

原生 JavaScript + CSS；esbuild 构建扩展，Vite 仅供本地界面预览。marked 解析 Markdown，DOMPurify 清理 HTML，YAML 安全解析 frontmatter。侧边栏负责编辑和解析；后台负责跨域图片获取；content script 仅在 X 长文编辑页运行适配器。通过 DOM 的富文本粘贴和图片文件粘贴交给 X 自身编辑器处理，不读取凭据或直接操作后端。

## 验收

Node 测试覆盖标题提取、富文本安全过滤、图片路径、正文分段、已有内容保护；浏览器验证窄侧栏、拖入/选择文件、草稿恢复、图片映射与错误提示。X 测试使用新建的明确标记测试草稿，不修改已有文章。若账号或浏览器阻止实际测试，准确记录已验证范围和待验证项。
